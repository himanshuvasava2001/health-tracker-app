# health-tracker-app

A lightweight health tracking web app built with plain HTML, CSS, and JavaScript.

Features:
- daily wellness summary for steps, water, sleep, and calories
- meal tracking with calorie totals
- workout tracking with duration and calorie burn
- weekly progress chart
- localStorage persistence so data stays available in the browser

How to run:
1. Open `index.html` directly in a browser, or
2. Run a local static server from the project folder:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

Project structure:
- `index.html` — app layout
- `styles.css` — styling and dashboard design
- `app.js` — health tracking logic and local storage
